# 时间线模板

> 本文件是全书的「时间账本」，记录世界纪年、大事件与故事正篇时间线。
> 时间一致性由 check_consistency.py 强制校验，任何新增剧情必须先更新本文件。
> 时间线混乱是常见状态漂移根源，请务必保持本文件为权威时间来源。

## 四、时间一致性自检

> 每卷结束后必须逐项打勾确认。

- [ ] 同一时间段内每个角色只出现在一个地点
- [ ] 路程时间合理（A 地到 B 地需要 X 天，不能瞬移）
- [ ] 年龄/生日/辈分计算正确
- [ ] 季节/天气前后一致
- [ ] 修炼/突破/疗伤所需时间与实力提升匹配
- [ ] 物品制造/消息传递/信件往来所需时间合理
- [ ] 孕妇/婴儿/儿童成长时间未出现异常（如 3 个月生小孩）
