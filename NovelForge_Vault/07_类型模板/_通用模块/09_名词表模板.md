# 名词表模板

> 本文件是全书的「专有名词字典」，所有世界观/力量体系/物品/地理/势力等专有名词必须在此登记。
> 与 `00_控制面/master_index.md` 联动：新增名词后需同步更新索引。
> 命名一致性由 check_consistency.py 强制校验，防止同一概念前后混用。

## 一、分类总览

> 先列出所有分类，后续新增名词归入对应分类。

| 分类 | 说明 | 示例 |
|---|---|---|
| 力量体系类 | 修炼等级、境界、能量名称、体质血脉等 | 斗之气/斗者/斗师、异火、神品血脉 |

| 地理类 | 大陆、国家、城市、山脉、秘境、特殊地点等 | 斗气大陆、加玛帝国、乌坦城、魔兽山脉 |
| 势力类 | 宗门、家族、帝国、协会、组织等 | 云岚宗、萧家、加玛皇室、炼药师协会、魂殿 |

## 三、命名一致性规范

> 每卷结束后必须逐项打勾确认。

- [ ] 同一概念全文统一用词（例：不混用「斗气」和「灵气」）
- [ ] 人名/地名无多音字歧义（易读错的字请在备注标注拼音）
- [ ] 同级别物品命名规则一致（例：丹药 XX 丹、法宝 XX 剑、功法 XX 诀/典/功）
- [ ] 同级别境界/修炼等级命名规则一致（例：斗者/斗师/大斗师/斗灵… 统一前缀）
- [ ] 势力名格式统一（例：XX 宗/XX 门/XX 家/XX 协会，不同后缀对应不同势力类型）
- [ ] 人物称号格式统一（例：XX 尊者/XX 皇/XX 帝，不同称号对应不同实力/身份等级）
- [ ] 无前后矛盾的定义（同一个词在不同章节含义不同 = 违规）
