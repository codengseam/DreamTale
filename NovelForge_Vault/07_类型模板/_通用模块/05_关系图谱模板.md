## 二、势力关系图

> 用 mermaid graph LR 语法绘制势力关系。先填空占位符，后按实际势力填写。

```mermaid
graph LR
    势力A -- 关系描述 --> 势力B
    势力B -- 关系描述 --> 势力C
    势力A -- 关系描述 --> 势力C
    势力D -- 关系描述 --> 势力A
    势力E -- 关系描述 --> 势力B
```

**文字说明**：
- 势力A = ____（待填写，示例：萧家）
- 势力B = ____（待填写）
- 势力C = ____（待填写）
- 势力D = ____（待填写）
- 势力E = ____（待填写）
- 关系说明：____（简要描述势力间合纵连横）
