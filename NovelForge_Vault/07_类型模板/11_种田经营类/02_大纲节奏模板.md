# 大纲节奏模板 · 种田经营类

> 本模板是【种田经营类】网文的大纲节奏骨架：**发展里程碑式**。
> 核心循环：**打基础 → 解锁新东西（建筑/配方/NPC）→ 小危机 → 小成就 → 扩张 → 大危机 → 翻盘里程碑**。
> 每卷 = 一个发展里程碑（例：村级→镇级 / 县城→州府 / 小镇→县城第一）+ 解锁新配方/新建筑/新NPC。
> 核心爽感来源：**细水长流的累积爽 + 解锁新东西的仪式感 + 危机憋 8 章后的大翻盘**。
> 配套设定模板：同目录「01_类型专属设定模板.md」。

---

## 一、种田节奏铁律（写之前先念 3 遍！）

1. **每 5 章一个「小成就」、每 20 章一个「大成就」（里程碑）**：
   - 小成就（5 章内）：赚了第一桶金 / 某个建筑升了级 / 招到了好 NPC / 解锁了新配方 / 某个产品大卖
   - 中成就（10-20 章）：第一个建筑满级 / 月纯利破 X 金 / 人口破 X 人 / 拿下第一个大客户订单
   - 大成就（卷末里程碑）：镇级→县级 / 县城第一 / 官方授勋 / 第一个传奇 NPC 加入 / 人口破百
2. **种田的爽是「细水长流的累积爽」，不是「一夜暴富的打脸爽」**：
   - 不要让主角一口气吃成胖子。今天建农场明天开连锁后天上市 = 读者弃书。积累感是种田文的命。
   - 每一步扩张都要有：「积累资金/物资 → 遇到瓶颈 → 找到突破点 → 扩张成功」四步。
3. **每 3 卷至少一次「大经营危机」，危机至少憋 8 章才翻盘**：
   - 大经营危机类型：资金链断裂 / 天灾（旱灾/蝗灾/暴风雪）/ 对手阴招（下毒/举报/截胡/挖人）/ NPC 背叛核心人才离职 / 政策变动（加税/禁商/限购）
   - 憋够 8 章 = 读者想摔手机 → 第 9 章主角亮出伏笔翻盘点 → 爽感直接顶满。
4. **NPC 要有成长和个人故事，不能只干活不说话**：
   - 每卷至少给 2 个重要 NPC 写 1-2 章个人支线（找对象 / 回家探亲 / 克服心结 / 报仇 / 收徒 / 生病）。
   - NPC 会跳槽、会结婚、会生老病死、会跟主角闹矛盾——有喜怒哀乐才是人，不是工具。
5. **「科技树解锁」和「新配方解锁」是大爽点，解锁时要有仪式感**：
   - 例：全村围观新磨坊剪彩 / 新菜品鉴会（请县里所有贵人来吃）/ 产品发布会 / 建筑封顶仪式 / 科技研究成功的烟花庆祝。
   - 解锁新东西一定要让第三方（NPC/路人/客户/贵人）看到、夸出来、震惊出来，比自己写爽 100 倍。
6. **可以混类型（修真+种田/末世+种田/星际+种田），但主线永远是「经营发展」**：
   - 打斗/修真/探索最多占 20%，不能写着写着变成纯玄幻/纯修真/纯打斗。
   - 哪怕主角境界再高，也要回领地种田、看账本、管 NPC、解决经营问题——这才是种田读者要的。

## 二、卷级结构模板（发展里程碑型 · 每卷复制一份）

> 标准种田单卷结构：**起（20%）：接手新摊子/破局点 → 承（40%）：基础建设+攒钱+招核心班底 → 转（25%）：扩张机遇+大型考验/大危机 → 合（15%）：里程碑达成+升级+下卷钩子**。

---

## 四、种田经营写作防坑清单（写完每卷后逐条核对！）

### ✅ 推荐写的（读者最爱看的 5+ 种内容）

1. ✅ **数据要自洽！拿个本子记下来**：一亩地产多少粮、养一头猪要多久、卖一碗面赚多少钱——每卷写完对照一下，别前后打架。
2. ✅ **「日常感」是灵魂（占 40% 以上）**：做饭、喂鸡、和 NPC 聊天、赶集、看日落、过年吃团圆饭、给员工发红包——这些温馨/琐碎的日常，才是种田文读者追更的核心动力。
3. ✅ **解锁新东西要有仪式感 + 第三方视角夸**：解锁新配方→开品鉴会请全县城贵人来吃 / 新建筑封顶→全村围观放鞭炮 / 科技研究成功→烟花庆祝。然后用路人/客户/贵人的嘴夸主角，比自己写爽 100 倍。
4. ✅ **NPC 要有个人故事 + 成长线（每卷 2 条支线）**：老陈头找孙女、落魄厨师克服心理阴影、小丫鬟从目不识丁→变成账房先生——读者追的不仅是主角，也是这些 NPC 的命运。
5. ✅ **危机至少憋 8 章再翻盘，翻盘一定要靠之前埋的伏笔**：不能凭空冒出来一个王爷救场，要 20 章前主角帮过一个乞丐，那个乞丐就是王爷——读者回头看会发现：「哦，原来伏笔早埋了！」，爽感翻倍。
6. ✅ **每 5 章一个小成就，数字要量化！**：别写「更有钱了」，写「月纯利从 100 金涨到 500 金」；别写「更多人了」，写「人口从 20 人破 100 人」——量化数字才有真实的累积感。

### ❌ 不要写的（种田文大忌，写了读者就弃！）

1. ❌ **不要让主角一口气吃成胖子（最严重红线！）**：今天租铺面明天开连锁后天上市 = 读者直接弃书。种田文的命就是「积累感」，每一步扩张都要有铺垫、有瓶颈、有代价。
2. ❌ **不要金手指变成「印钞机」**：金手指是「加速器」不是「无中生有」。随身空间有多大、灵泉每天多少斤、系统有冷却——边界要卡死，不能无限用。
3. ❌ **不要 NPC 全是工具人**：每个核心 NPC 都是「人」不是「干活机器」——他们会结婚、会生病、会跳槽、会想家、会跟主角闹矛盾。全是工具人的种田文，没人味，读者看 50 章就腻了。
4. ❌ **不要写着写着变成纯玄幻/纯打斗**：如果是「修真+种田」，打斗/修真最多占 20%，主角哪怕成了仙人也要回领地种田、看账本、管 NPC。把经营丢了去写打斗，等于把种田读者最想看的东西丢了。
5. ❌ **不要危机秒解决！憋 8 章才是爽**：危机刚出现第 2 章就解决 = 白写。憋 8 章：第 1-2 章危机出现、第 3-5 章雪上加霜、第 6-7 章读者想弃书、第 8 章主角翻盘——爽感才顶满。
6. ❌ **不要感情线开后宫 + 上来就搞暧昧**：种田文感情线要「细水长流」——一起干活、一起吃苦、一起熬过危机，感情水到渠成。后宫文读者和种田文读者重合度不高，开后宫容易两边不讨好。
