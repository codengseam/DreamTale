# 网文类型设定模板体系 · NovelForge

> 本目录是 NovelForge 的「类型模板库」——为不同类型的网文预置了设定骨架，创作时直接复制对应类型的模板作为起点参考，避免遗漏核心设定。

## 一、整体架构：通用模块 + 类型专属模块

```
设定体系 = 通用模块（所有类型必看，9个） + 类型专属模块（选你写的类型看，每个类型2个）
```

## 三、使用流程

```
Step 1：确定类型（支持混合类型，如「都市+异能」「修真+种田」）
  │
Step 2：打开本目录，先读「_通用模块/」下9个模板，把基础框架填好
  │
Step 3：打开对应类型目录，读「01_类型专属设定模板.md」，按需勾选填写
  │         如果是混合类型（如「都市+种田」），两个类型的专属模板都看，合并字段
  │
Step 4：读该类型「02_大纲节奏模板.md」，按建议的节奏结构搭卷纲
  │
Step 5：进入 NovelForge 主流程：填充世界观→角色→大纲→伏笔→开写
```

### 混合类型怎么处理？

例：写「都市 + 种田 + 异能」三线混合：
1. 先填「_通用模块」9个（任何类型都要）
2. 读「05_都市类/01_类型专属设定模板.md」→ 子类A（都市异能）的部分填完
3. 读「11_种田经营类/01_类型专属设定模板.md」→ 经营对象、资源循环、建设树填完
4. 大纲节奏选主线节奏：如果主线是经营就用种田的节奏模板，穿插都市异能的事件
5. 字段冲突时，以**主线类型**的字段为准，支线类型的字段作为补充

## 四、模板的本质是什么？

> **模板不是限制，而是「不遗漏」。**

很多新人作者写网游小说，写到200章突然发现「我没设定转职系统」，然后硬编一个，前后矛盾。模板的作用是：

1. ✅ 在开书前**提醒**你「这些你考虑过吗？」
2. ✅ 不是每个字段都必须填，但**至少想过**
3. ✅ 填不了的可以先标「待定/后续展开」，但框架在那里
4. ✅ 可以**增删改**：模板只是起点，你可以把不需要的模块删掉，把需要的自定义模块加进来

## 五、自定义模块建议

如果现有11种类型都不够（比如你写的是极其小众的类型：赛马/体育竞技/律师行业文/美食文…）：

1. 在 `07_类型模板/` 下新建目录，如 `12_美食文类/`
2. 复制任意一种接近的类型的2个文件作为起点
3. 修改字段为你这个类型专属的（比如美食文加「菜谱评级体系」「食评家体系」「比赛规则」）
4. 在本 README 的「类型专属模块」表格中追加一行（可选，方便以后找）
