# 大纲节奏模板 · 修真仙侠类

> 本模板是【修真/仙侠类】网文的大纲节奏骨架：**悟道驱动型**——比玄幻慢热，更重「悟」和「劫」。
> 核心循环：**入世历练 → 积攒因果 → 遇心魔 → 顿悟 → 渡劫 → 了断因果**。
> 每卷 = 一次大境界突破 + 一次心境成长 + 渡一次大天劫。
> 配套设定模板：同目录「01_类型专属设定模板.md」。

---

## 一、修真节奏铁律（写之前先默念）

1. **修炼 ≠ 打坐升级**：升级必须有「心境感悟」或「历劫」或「积累够了 + 一个顿悟契机」。纯打坐升级 = 玄幻换皮。
2. **升级速度比玄幻慢 30%，但每一级的含金量更高**：读者会记住「主角金丹有多牛逼」而不是「主角又升级了」。
3. **必写「瓶颈期」**：每个大境界至少卡一次，给读者期待感。卡的时间越长，突破时的爽感越强。
4. **「仙气感」来自意象，不是来自辞藻堆砌**：多写云海、松涛、明月、仙鹤、古钟、香炉、御剑乘风的画面感；不要每句话都加「仙风道骨」四个字。
5. **因果要闭环**：欠的恩要报、结的仇要了、种的因要结果——不然业力会让你渡劫翻车。
6. **修真 = 向内求（悟道修心）vs 玄幻 = 向外求（资源升级）**：内核不要写混。

## 二、卷级结构模板（悟道驱动型 · 每卷复制一份）

> 标准修真单卷结构：**起（入世历炼20%） → 承（积蕴+修心40%） → 转（天劫+悟道25%） → 合（破境+了断因果15%）**。

## 四、修真写作特色提醒（仙气感怎么来？）

### ✅ 推荐这样写（意象 = 仙气）

1. ✅ **用自然意象写悟道过程**：
   - 剑 → 松、竹、石、风、月
   - 火 → 炉、烛、日、霞、岩浆
   - 水 → 瀑、湖、海、雨、泉
   - 例：「他站在瀑布下坐了三天三夜，任水花溅湿青衫。第四天清晨，他抬指一指，一道剑气顺着瀑布流势而出——不是斩断水流，是顺着水流，剑和水成了一体，水中无剑、剑中含水。」

2. ✅ **修真者的日常细节 = 仙气**：
   - 清晨在山巅吐纳朝霞（不是睡懒觉）
   - 泡茶用去年收的梅上雪
   - 打坐前焚一炉凝神香
   - 御的剑不是普通宝剑，是自己炼的、有名字的、温养多年的本命剑（剑的名字也要有仙气：青冥、白虹、碎星、流光、湛卢…）

3. ✅ **分层次的「仙气鄙视链」**：
   - 低阶修士：腾云驾雾（衣服会被风吹皱）
   - 中阶修士：御剑飞行（剑上还站不稳）
   - 高阶修士：凌空而行（脚下生莲/步步生云）
   - 大乘/仙人：一念即至（本体不动，神念已到万里外）
   - 不要让高阶修士还在「腾云驾雾」，掉价！

### ❌ 不要把修真写成玄幻换皮

1. ❌ **修真 ≠ 玄幻把斗气改成灵气**：
   - 玄幻打架：拼谁的能量多、谁的大招炫
   - 修真打架：拼谁的道更接近真理、谁的心境更稳、谁身上的业力更少（业力多的人雷劫帮你劈死他）

2. ❌ **不要让主角满脑子都是升级**：
   - 真修士要有「道心」：想清楚「我为什么修仙？」「是为了长生？为了保护？为了报仇？为了见道？」
   - 每隔几卷让主角问自己一次这个问题（答案会变，这就是弧光）

3. ❌ **不要把渡劫写成「扛雷就行」**：
   - 雷劫只是天劫的外衣，内核是：**心魔劫 = 你心中放不下的执念**、**业火劫 = 你杀过的人/欠的债来讨债了**
   - 渡劫时要把主角的过往「放电影」一样在识海里过一遍：被他杀的无辜者、救过的人、错过的事、放不下的执念
