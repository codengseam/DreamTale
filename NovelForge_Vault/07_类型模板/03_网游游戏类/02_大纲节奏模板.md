# 大纲节奏模板 · 网游/游戏类

> 本模板是【网游/游戏类】网文的大纲节奏骨架：**副本/赛季循环式**。
> 核心循环：**副本开荒 → 升级拿装备 → PVP 打脸 → 公会战/国战 → 版本更新 → 新地图 → 更大副本**
> 每卷 = 一次大副本/一个赛季/一次大版本更新。
> 配套设定模板：同目录「01_类型专属设定模板.md」。

---

## 一、网游节奏铁律（写之前先念 3 遍）

1. **每 3 章一个小目标、每 10 章一个中目标、每卷一个大目标**：
   - 小目标（3 章）：升一级 / 出一件装备 / 完成一个日常任务
   - 中目标（10 章）：过一个副本 / 打一次小副本首杀 / 竞技场升一段
   - 大目标（卷）：版本首杀 / 赛季冠军 / 建公会拿城 / 满级
2. **系统提示/公告是爽感放大器**：主角的事迹一定要通过「全服公告」「等级榜/战力榜排名上升」「广播」让全服玩家看到，这是装逼的一部分。
3. **数值要自洽**：打一个怪多少经验、升级要多少、装备加多少战力、XX 金币换 1 块钱——算清楚，别前后矛盾（例：前一章说 100 金=1 元，后一章主角有 10000 金就成了首富=矛盾）。
4. **不要过度堆属性面板**：别每章都贴一整页主角的属性面板。升级的时候、打 BOSS 前、拿到新装备的时候贴一次就行，其他时候一笔带过（「他现在的物攻已经突破了 1 万，比同等级的战士高 30%」）。
5. **主角不能每次都是全世界唯一**：隐藏任务/首杀，可以是「第一个」但最好不是「唯一一个」——后面也有人完成（只是慢一点），这样比较真实。唯一的那种「全服唯一一个隐藏职业」整本小说最多 1 次，别次次都是。
6. **赛季/版本更新是「时间节点」也是「爽感重置点」**：新版本一开，等级上限提高、新装备出来、大家又回到同一起跑线，主角靠先知先觉/BUG/特殊准备再次领先——这就是网游文的「换地图=换卷」。

## 二、卷级结构模板（赛季/版本驱动型 · 每卷复制一份）

> 标准网游单卷结构：**起（新版本 + 新地图入场 20%） → 承（副本开荒 + 升级 + 公会发展 40%） → 转（赛季高潮 + 重大变故 25%） → 合（赛季结算 + 下版本预告 15%）**。

## 四、网游/电竞写作防坑清单（写完每卷后逐条核对！）

### ✅ 推荐写的

1. ✅ **系统提示要格式化！** 像真游戏一样，不同颜色/前缀/【括号】，读者看着有代入感：
   - 【全服公告】（金色、加粗）
   - 【战斗日志】（红色伤害数字 / 绿色治疗数字）
   - 【队伍频道】【公会频道】【世界频道】（前缀+玩家名+不同颜色）
   - 例：「【队伍】『土豪王哥』：卧槽兄弟你这伤害？？你是挂吧？？」
2. ✅ **数值要自洽**：每写一卷，拿张纸/文档记下来：当前等级、装备、攻击/防御/HP、货币汇率、首杀奖励——别前后打架。
3. ✅ **直播/论坛/贴吧剧情（20% 比例穿插）**：读者超爱看「第三方视角吹主角」！每隔 5-10 章插一段论坛帖子/直播弹幕/解说激情语录，用路人的嘴夸主角，比自己夸爽 100 倍。
4. ✅ **BOSS 要有机制不能只有数值**：好的副本 BOSS 至少 3 个技能：① 全屏 AOE 要躲 ② 点名技能要分摊/跑位 ③ 转阶段无敌 + 狂暴（例：血量 30% 以下攻速翻倍）。灭团就灭在机制上，不是数值碾压，读者才觉得真实。

### ❌ 不要写的（烂大街/被骂的坑）

1. ❌ **不要「叮！恭喜宿主获得 XX」系统流模板乱入**：如果你写的是「网游」不是「系统+网游」，就别搞那种「系统给任务」「系统给奖励」——任务是游戏 NPC 给的，奖励是 BOSS 掉的，别搞混。
2. ❌ **不要让主角一个人单刷 40 人团本 BOSS**：哪怕你是隐藏职业，也别一个人秒全场。网游=团队游戏，队友的作用要写出来（奶妈加血、T 抗怪、控场控 BOSS），主角是输出核心但不是唯一。
3. ❌ **不要每章末尾都是「XXX 大怒：好小子你给我等着！」**：打脸要有来有回，别每次反派都是放狠话然后被秒，反派也要有智商（哪怕只高一点点）。
4. ❌ **不要把女主/女玩家写成「只会躺赢喊 666」**：网游文女读者也不少！女主可以是操作一流的奶妈/法师/会长，有自己的想法和能力，不是主角的挂件。
5. ❌ **不要过度堆砌专业电竞术语**（电竞向）：写 MOBA 游戏可以写「拉扯」「运营」「开团」「视野」，但别整篇都是「B/P 分析」「英雄池 counter 分析」——非硬核读者看不懂就弃了，术语比例控制在 10% 以内，用剧情/人物来解释术语。
