# 大纲节奏模板 · 玄幻类

> 本模板是【玄幻类】网文的大纲节奏骨架：**地图递进式**——小地图 → 大地图 → 更大地图 → 上界/位面。
> 核心循环：**打脸 → 升级 → 换地图**，每个循环嵌套「扮猪吃虎 → 藏拙 → 爆发 → 震惊 → 收获」。
> 配套设定模板：同目录「01_类型专属设定模板.md」。

---

## 一、玄幻节奏铁律（写之前先默念 3 遍）

1. **压抑不得连续超过 3 章**：连续 3 章都在虐主角、都在被看不起、都在憋，读者直接弃书。每 5 章内至少一个小爽点。
2. **每次换地图后，主角必须至少「降一级」**：新地图里主角实力要在本地的最底层（或倒数第二层），再重新崛起——保持爽感来源。禁止主角到了新地图还是横着走（除非是中期回新手村装逼，那另算）。
3. **「震惊路人」不能千篇一律**：至少分 3 层反应——不信/嘲讽 → 将信将疑/怀疑 → 服气/倒吸凉气/嫉妒疯了/当场拜师。不要每次都写「全场死寂」「倒吸一口凉气」「恐怖如斯」，换点花样。
4. **每次境界突破要有代价**：受伤 / 消耗大量资源 / 被追杀 / 金手指沉睡 / 经脉受损 / 错过重要的人。没有代价的突破 = 金手指不值钱 = 爽感稀释。
5. **每个地图的冲突模式要换**：新手村是家族内斗 → 下一张地图是宗门大比 → 下一张是国家战争 → 再下一张是位面入侵。不要次次都是「有人看不起主角然后被打脸」，会审美疲劳。
6. **卷与卷的节奏不重复**：上一卷连续打脸、节奏快，这一卷就该「蓄势 + 铺垫 + 卷末大爆发」，给读者喘息和期待的空间。

## 二、卷级结构模板（每卷复制一份填写）

> 标准玄幻单卷结构：**起（入场踩坑 20%） → 承（蓄势小爽 40%） → 转（绝境爆发 25%） → 合（高潮钩子 15%）**。

---

### 起（20%）· 入场与踩坑

#### 核心任务：新地图入场 + 踩坑树敌 + 金手指新用法解锁

| 节点 | 内容要求 | 对应章节（例 Ch1-Ch10） | 爽压值（1-5，爽★/压●） |
|---|---|---|---|
| 新地图入场见闻 | **用主角的眼睛展示新世界**（禁止上帝视角大段设定！）。主角走在新城市/新宗门的路上，看到什么建筑、听到什么路人对话、感受到什么境界威压。 | Ch____-Ch____ | ★● （好奇+陌生感） |
| 不懂规则踩坑/被看不起 | 主角因为是外来者/新人/底层 → 不懂新地图的潜规则 → 被讹/被羞辱/被安排最差的位置/被故意针对。（例：进入宗门被分到最差的洞府、拍卖会报出低价被全场嘲笑、排队被插队反被骂） | Ch____-Ch____ | ●●●● （积愤） |
| 第一个小冲突/树第一个本地小敌 | 某个本地小角色（纨绔/老弟子/地头蛇）主动挑衅，主角隐忍不发（或小反击但藏拙），但梁子结下了。 | Ch____-Ch____ | ●●● （憋） |
| 金手指在新地图的新用法解锁 | 进入新地图后，金手指因为环境（灵气更浓/有特殊材料/遇到特殊的人）**解锁了一个新功能**。例：系统解锁新任务、老爷爷拿出新功法、混沌体吸收了本地独特气息觉醒新能力。 | Ch____-Ch____ | ★★★ （期待感↑） |
| **第一章结尾钩子** | 抛出一个小悬念，让读者愿意点下一卷/下一章。例：主角突然感应到秘境即将开启、第一宗门长老当众宣布要亲自考核新人、小反派放话「三天后的入门大比我要你跪着求我」。 | Ch____ 卷首末尾 | ★★ （钩子） |

### 承（40%）· 蓄势与小爽

#### 核心任务：融入势力 + 连续扮猪吃虎（≥3次递进） + 中段瓶颈/代价

| 节点 | 内容要求 | 对应章节 | 爽压值 |
|---|---|---|---|
| 融入势力（宗门/学院/家族） | 主角通过入门考核/加入组织/被引荐 → 获得身份、资源、修炼地。过程中展示一点小实力但**隐藏大部分**（扮猪）。 | Ch____-Ch____ | ★● |
| **第一次扮猪吃虎（小打脸）** | 之前的小反派主动上门找茬（抢洞府/抢资源/赌斗），主角隐忍到关键时刻小爆发，赢了但**留力**。围观路人反应：「咦？这小子有点东西，但还是不够看」。 | Ch____-Ch____ | ★★★ （第一次泄愤） |
| 立住 3 个核心配角 | 本卷必须立：1 个盟友（兄弟/师姐/导师）、1 个暧昧对象、1 个强力对手（本卷大反派的小弟）。每人至少一场个人秀，别写成工具人。 | Ch____-Ch____ | ★★ （期待配角互动） |
| **第二次扮猪吃虎（中打脸）** | 某个比上次强一档的角色（核心弟子/富二代/外门第一）当众挑衅/针对主角朋友或暧昧对象 → 主角被迫出手，赢了但赢得很「险」（其实很轻松但故意装）。路人反应：从「他肯定输」→「卧槽赢了？」→「不对，他好像还留力？」 | Ch____-Ch____ | ★★★★ （爽感累积） |
| 资源收集 + 境界蓄势 | 主角用金手指收集本地图独特资源：进入小秘境、兑换特殊功法、收服第一只灵兽/契约第一把本命兵器。**冲击一个小境界**（例：从初期到中期）。 | Ch____-Ch____ | ★★★ （稳定成长） |
| **中段瓶颈/代价（必须有！）** | 修炼遇到瓶颈 / 突破失败 / 受伤 / 被重要的人误会 / 金手指出问题（沉睡/能量耗尽） / 被卷入一场阴谋。情绪从一路上升突然往下压一下，读者心被揪住。 | Ch____-Ch____ | ●●●● （急转直下） |
| **第三次扮猪吃虎（大打脸）** | 中段瓶颈之后，主角破局（突破/领悟/金手指恢复），在一个正式场合（宗门大比/拍卖会竞价/秘境争夺）正面刚上本卷二号反派，完胜！路人反应分三层：不信→傻了→疯了。 | Ch____-Ch____ | ★★★★★ （本卷最高点前的预热） |
| 本卷大反派正式盯上主角 | 大反派注意到主角的异常，开始布局：派人试探/给主角下套/联合其他势力打压主角。暗示：「下一轮，才是真正的地狱」。 | Ch____-Ch____ | ★● （爽中带忧，期待爆发） |

### 转（25%）· 绝境与爆发

#### 核心任务：大反派布局 → 主角退无可退 → 关键突破（有代价） + 底牌尽出

| 节点 | 内容要求 | 对应章节 | 爽压值 |
|---|---|---|---|
| 大反派布局收网 | 大反派的阴谋正式启动：主角被诬陷/被围攻/被困秘境/朋友被抓/势力被围。主角一方从优势瞬间跌入绝境。 | Ch____-Ch____ | ●●●●● （憋到极点） |
| **退无可退的时刻** | 所有常规手段都无效：逃不掉、打不过、盟友重伤、金手指暂时无法用。主角必须做一个抉择：是牺牲什么东西，还是放弃，还是孤注一掷？ | Ch____-Ch____ | ●●●●● + （读者揪心） |
| **关键突破 + 代价（全书/本卷最重要节点之一！）** | 主角在绝境中，因为某个契机（看到朋友受伤/想到亲人/回想起初心/被敌人嘲讽戳到痛处） → **突破一个大境界** 或 **解锁金手指的隐藏模式**！★但必须有代价★：经脉受损/金手指沉睡一月/寿元缩减/朋友替自己挡了一刀重伤濒死。 | Ch____-Ch____ | ★★★★★（爆发！但读者心里有隐忧） |
| 金手指底牌尽出 | 主角用上了所有压箱底的东西：隐藏功法、最后一张符箓、老爷爷附体、燃烧精血、召唤契约兽。这一仗把能用的全部用完。 | Ch____-Ch____ | ★★★★★（高潮持续） |
| 与本卷大反派的终极对决（前半段） | 前期大反派占优（毕竟境界高/人多），主角被压制。直到主角用出某招（顿悟的新招式/之前埋伏的后手），局势反转。 | Ch____-Ch____ | ★●★●（拉锯） |

### 合（15%）· 高潮与钩子

#### 核心任务：卷末大高潮 → 地位跃迁 + 境界提升（卡天花板-1） → 下卷强钩子

| 节点 | 内容要求 | 对应章节 | 爽压值 |
|---|---|---|---|
| **卷末大高潮（终极对决后半段）** | 正面硬刚大反派！每 2-3 段一个反转，最后一招定胜负。胜利后不要立刻收，写清楚：大反派怎么死/逃/败、围观者的分层反应（盟友哭了、敌人崩溃、路人疯了）、主角方所有人的心情。 | Ch____-Ch____ | ★★★★★★（超满分，本卷最爽的一章） |
| **主角地位跃迁** | 从本卷开始时的最底层，跃迁到本地势力的高层：例：外门弟子 → 内门真传、寒门少年 → 封王拜将、无名散修 → 一方巨擘。附带奖励：资源、功法、身份令牌、长辈赏赐。 | Ch____-Ch____ | ★★★★ （兑现期待） |
| **境界突破（但卡在「新地图天花板-1级」）** | 打赢之后顺势突破一个境界（或稳固），但！**不要突破到本地最强那级**，留 1 级到下卷/回到这里时再突破，保持悬念。 | Ch____-Ch____ | ★★★ （稳） |
| **了断本卷因果 + 处理本卷代价** | 该感谢的感谢、该报仇的报仇、该治疗的治疗、代价的后果显现（金手指睡了/受伤了/朋友昏迷了）。让这个卷的故事闭环。 | Ch____-Ch____ | ★● （闭环） |
| **下卷钩子（必须是 3 选 1 以上叠加）** | □ **更大世界召唤**：上界来人/更高级势力的邀请函/秘境出口连通另一个大陆<br>□ **新敌人登场**：大反派背后的靠山（师兄/师父/父亲/家族）找上门来放狠话<br>□ **旧敌升级**：之前逃走的反派在新地图卷土重来，实力暴涨<br>□ **金手指的一丝线索**：突然揭示金手指来历的冰山一角（例：老爷爷看到某件信物脸色大变） | Ch____ 本卷末章 | ★★★★（读者追下去的动力！） |

## 四、常见玄幻梗避免清单（防查重、防 AI 味、防读者弃书）

### ❌ 不要写的烂大街梗（除非你能写出花）

1. ❌ **路人反应流水线**：不要每次都是「全场死寂」「倒吸一口凉气」「恐怖如斯！」。换着写：
   - 老年人：「此子…不可留！老夫生平仅见！」
   - 同辈：「怎么可能？他明明只有 ____ 境界！」
   - 敌人：「不可能！我不信！」（然后被秒）
   - 女弟子：「哇！他好帅！好厉害！」（仅限轻松向，爽文少写）
2. ❌ **拍卖会神秘包厢土豪**：每次竞价最后总有个「三楼包厢的神秘买家」出价。建议：拍卖会可以换个玩法（暗拍、抢拍、拍出去被截杀、主角其实是主办方）。
3. ❌ **退婚/废柴流开局**：10 本玄幻 8 本退婚。除非你有 100 种方式写出新意，否则换个开局。
4. ❌ **「叮！检测到宿主XX，奖励XX」** 系统流泛滥。如果是系统流，至少给系统加个「性格」（毒舌系统/傲娇系统/要和宿主谈恋爱的系统）。
5. ❌ **丹药拍卖会四品丹药抢破头**：后面八品九品还怎么写？品阶递进要合理。

### ✅ 每次打脸的分层反应模板（直接抄）

| 人物类型 | 被打脸前（嘲讽） | 过程中（怀疑） | 被打脸后（震惊） | 后续行为（5选1-2） |
|---|---|---|---|---|
| 普通路人/弟子 | 「____ 也配？滚下去吧！」 | 「咦？好像…有点东西？不对，是巧合！」 | 「什么！！我瞎了？？」 | 倒吸凉气 / 鸦雀无声 / 交头接耳 |
| 有实力但嫉妒主角的同辈 | 「装腔作势！一会让你跪地求饶！」 | 「他怎么可能接住这招？……」 | 「不可能！我不信！再来！（然后又被秒）」 | 脸涨成猪肝色 / 当场跪地 / 想逃被抓回来 |
| 长辈/长老级 | 「年轻人不知天高地厚，需知人外有人。」 | 「这招式…此子不简单！」 | 「此子天赋堪比 ____ 辈！我不如也！」 | 立刻想要收徒 / 主动送装备功法 / 当场改口叫「小友」 |
| 主角盟友/朋友 | 「小心啊！（担心）」 | 「卧槽？炎哥/叶哥这么猛？」 | 「我靠！我就知道你可以！！」 | 冲上去抱/拍肩 / 比主角还激动 / 嘲讽刚看笑话的人 |
| 本卷大反派/他的狗腿子 | 「蝼蚁之力，也敢与皓月争辉？」 | 「嗯？有点意思，看来我低估你了。」（但还没慌） | 「怎么可能！你怎么会 ____ 功法！」 | 脸色铁青 / 当场放狠话（我爹是XX/我师父是XX） / 动用底牌还是输 |
